therealjimwilliams-dot-com
==========================

This site began as an attempt to re-create my first interactions with a computer:  the Apple ][+

When you turned it on, all you got was a prompt, so that's where I started. 

It grew from there;  Quickly i pivoted into creating a MUD where people could interact in real time.  

Everything was written from scratch, with the except being jQuery.   

This version is left in tact for reference; there's alot of good stuff in here.

Development on this fizzled out as I began to struggle with phone UI.   

This work has taken new life in playdoink.com
